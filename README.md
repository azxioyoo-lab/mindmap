# 🧠 MindMap — 轻量级在线思维导图工具

> 无需安装，打开即用。纯前端实现，零依赖，完全免费。

**[🚀 立即体验 Live Demo](https://azxioyoo-lab.github.io/mindmap)**

---

## ✨ 功能特性

- 🖱️ **拖拽操作** — 自由拖动节点，直觉化布局
- 🔗 **自由连线** — 任意节点之间建立连接关系
- 🎨 **多色主题** — 内置多套配色，支持自定义颜色
- 📁 **历史记录** — 自动保存，随时找回之前的导图
- ↩️ **撤销/重做** — 完整的操作历史，Ctrl+Z 随时回退
- 🔍 **缩放平移** — 鼠标滚轮缩放，中键平移画布
- 📤 **导出功能** — 支持导出为 PNG / PDF
- 🗂️ **节点层级** — 支持多层级结构，可折叠展开
- 📝 **节点备注** — 每个节点支持附加说明文字
- 💾 **本地存储** — 数据保存在浏览器，无需账号

---

## 🚀 快速开始

**方式一：在线使用**
直接访问 👉 [https://azxioyoo-lab.github.io/mindmap](https://azxioyoo-lab.github.io/mindmap)

**方式二：本地运行**
```bash
git clone https://github.com/azxioyoo-lab/mindmap.git
cd mindmap
# 直接用浏览器打开 index.html 即可
open index.html
```

**方式三：自部署**
下载 `index.html`，放到任意 Web 服务器即可，单文件无依赖。

## 🎮 操作指南

| 操作 | 说明 |
|------|------|
| 单击节点 | 选中节点 |
| 双击节点 | 编辑节点文字 |
| 拖动节点 | 移动位置 |
| 节点边缘拖出 | 创建连线 |
| 滚轮 | 缩放画布 |
| 空白处拖动 | 平移画布 |
| `Tab` | 添加子节点 |
| `Del` | 删除选中节点 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `Ctrl+A` | 全选 |
